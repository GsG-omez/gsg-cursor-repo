  • Identity

    SSO that worked in staging, not production

    Production SSO started completing after the same SAML setup that worked in staging failed in prod — the mismatch was on the service-provider side (sign-in URL and .pem/.cert), not a broken customer IdP.

    The surface I own is reading the error and finding the cause. We consume the customer’s IdP through the product UI (SAML or OAuth via Auth0) — we don’t architect their identity tenant. I compared the failed assertion and the Sign-in URL / certificate against staging, found the prod values didn’t match, and wrote that check down so the next identical failure wasn’t a black box.

    • SAML
    • OAuth
    • Auth0

    Turned a two-account config ticket into a platform incident and got metrics restored the same day — root cause was a Prometheus 3.0 upgrade that broke a query the accounts API depended on.

    Two accounts suddenly saw a “Get started” page and 500s instead of their metrics plan. I escalated with errors and screenshots, then found the same failure on a second unrelated account — which turned a “customer config” ticket into a platform incident. A Prometheus 3.0 upgrade had broken a query the accounts API used. Incident channel opened; restored the same day.
